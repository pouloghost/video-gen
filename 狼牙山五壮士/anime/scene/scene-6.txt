# Prompt types
- Pure text, generative prompting, a new image is generated by purely describing all details by text. This type is best for model to liberate. Denoted as Text.
- Reference image with text, generative prompting, a new image is generated by text, but key character or setting is provided using other images. This type is best for the first key frame with important character and setting. Denoted as Ref. 
  If the scene is simple and concise, follow the Text prompting pattern, add referenced image in prompt.
  If the scene is a little bit complicated, use Ref workflow. First generate a simple sketch to show the plot and composition, then remix with the refered images.
- Modify image with text, a new image is generated by modify an existing image. This type is best for animating one frame into next one, maintaining consistance. Denoted as Modify.
You can choose from these types of prompting.

# Generative prompt guidelines
The goal is to provide a comprehensive description that not only outlines the subject matter but also guides the AI on the desired photographic qualities, mood, and technical aspects. Think like a photographer planning a shot.

**I. Core Subject and Scene Description:**
*   **What is the main subject?** Be precise (e.g., "three young Chinese women,").
*   **What are they doing?** (e.g., "standing side-by-side,").
*   **What are their key characteristics?** (e.g., "exquisite traditional Hanfu,").
*   **Are there any specific props?** (e.g., "ornamental circular fans,").
*   **What is the setting/environment?** (e.g., "ancient Chinese palace architecture,").
*   **Any specific background elements?** (e.g., "red walls, golden roofs, stone balustrade,").

**II. Photographic Technicals (The "How"):**
1.  **Exposure Triangle:**
    *   **ISO:** Specify a low ISO for clean images (e.g., "ISO 100", "ISO 200").
    *   **Aperture (f-stop):** Crucial for Depth of Field.
    *   **Shutter Speed:** Influences motion blur and light.
2.  **Lighting:**
    *   **Type:** "natural daylight,", "studio lighting,", "artificial light,", "moonlight.", etc.
    *   **Quality/Direction:** "golden hour lighting,", "soft diffused lighting,", "hard direct sunlight,", "rim light,", "backlight,", "front light,", "dramatic chiaroscuro.", etc.
    *   **Color Temperature:** "warm tones,", "cool tones,", "neutral.", etc.
3.  **Composition:**
    *   **Rule of Thirds:** "subjects centered and slightly to the right/left,", "horizon on lower third.", etc.
    *   **Leading Lines:** "leading lines from the balustrade/road/river.", etc.
    *   **Symmetry:** "symmetrical composition.", etc.
    *   **Framing:** "natural framing by doorway/trees.", etc.
    *   **Negative Space:** "emphasizing negative space around subject.", etc.
    *   **Rule of Odds:** "odd number of subjects.", etc.
    *   **Perspective:** "low-angle,", "high-angle,", "worm's-eye view", "bird's-eye view.", etc.
4.  **Depth of Field (DoF):**
    *   **Shallow:**
    *   **Deep/Large:**
5.  **Bokeh:**
    *   **Presence:** "creamy bokeh," "smooth bokeh," "busy bokeh," "noticeable bokeh circles."
    *   **Quality:** "soft background blur," "dreamy background blur."
6.  **Lens & Focal Length:**
    *   **Type:** "prime lens," "zoom lens," "telephoto lens," "wide-angle lens," "macro lens," "fisheye lens."
    *   **Specific Focal Length:** "85mm," "50mm," "24mm," "200mm." (This implies perspective compression/expansion).
7.  **Genre/Style/Mood:**
    *   **Genre:** "cultural portraiture," "environmental portraiture," "street photography," "landscape photography," "fine art," "documentary," "fashion."
    *   **Style:** "warm, vibrant, high-key," "moody, cinematic, low-key," "vintage, sepia tone," "monochrome, black and white," "dreamy," "realistic," "hyperrealistic."
    *   **Mood:** "serene," "dramatic," "joyful," "mysterious."
8.  **Camera Angle & Shot Type:**
    *   **Angle:** "eye level," "low angle," "high angle," "Dutch angle."
    *   **Shot Type:** "full shot," "medium shot," "close-up," "wide shot," "establishing shot."

**III. Structuring the Prompt:**
*   **Start with the broad strokes:** Shot type, main subjects, core action.
*   **Integrate technical details:** Weave in exposure, composition, lighting, DoF, lens. You can group them or spread them logically.
*   **Add stylistic elements:** Genre, mood, color palette.
*   **Be specific:** Instead of "good lighting," use "golden hour lighting, soft diffused." Instead of "blurry background," use "shallow depth of field, creamy bokeh."
*   **Use strong descriptive adjectives.**
*   **Think about the desired *feeling* of the image** and translate that into photographic terms.

# Remix prompt guidelines
1. Primary Objective
Your task is to modify and enrich a base image prompt. The base prompt or an accompanying line art file defines the core composition, layout, and narrative action.
Your modifications must not change these fundamental structural elements (e.g., character positions, poses, or the primary action).
Your sole focus is to inject rich visual detail, style, and atmosphere—elements that line art cannot express.
2. Core Focus Areas: Additive Detailing
Concentrate on adding descriptive language for the following visual components:
*  **Visual Style & Rendering:**
Art Style: Be explicit. (e.g., photorealistic, cinematic, etc.).
Textures & Materials: Describe the "feel" of surfaces. (e.g., rough wool sweater, wet, etc.).
*  **Lighting & Atmosphere:**
Source & Quality: Define the light. (e.g., dramatic chiaroscuro, soft golden hour backlighting, etc.).
Shadows: Describe the shadow properties. (e.g., long, hard-edged shadows, soft, diffused shadows, etc.).
*  **Atmospheric Effects:** Add depth. (e.g., volumetric fog, glowing particle effects, lens flare, etc.).
*  **Color Palette:**
Define the entire scene's color mood. (e.g., monochromatic blue palette, vibrant neon colors, etc.).
*  **Detailed Expressions & Nuance:**
Go beyond simple "sad" or "happy." Describe the specific facial muscles. (e.g., a slight knowing smirk, furrowed brow with worried eyes, etc.).
3. Constraints: What to Avoid
DO NOT modify composition. (e.g., "Move Character A to the right" is forbidden).
DO NOT change character poses or core physical actions.
DO NOT introduce new narrative elements or plot points. The story is already set.
4. Mandatory Identification & Referencing
To ensure clarity, all modifications must follow this structure:
Explicit Naming: Clearly identify the character or entity being described. Use their established names (e.g., Wang Yu, the villain, the central artifact).
Positional Anchoring: State the entity's location to anchor the description, even if it's unchanged. (e.g., Wang Yu (foreground left), the villain (background, center)).
Reference Image Linking: All new stylistic, lighting, or expression details must be explicitly linked to a provided reference image.
Example: "For Character A (foreground left), apply the features from Image 3 and the jacket texture from Image 5. Change facial expression to furrowed brow with worried eyes."
5. Length
Be concise, less than 600 words.

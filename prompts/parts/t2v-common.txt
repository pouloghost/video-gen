# Ref image
The character and setting image is uploaded to the text-to-image model. You can ref them by mentioning their filenames, the character file is named as 'character-`character_id`'; the setting file is named as 'setting-`setting_id`'.
The setting image is always full view. The character is always full body portrait. Prompt to use part of the ref image if necessary.
